# Observatory Photographer

A plugin for [Observatory Core](https://observatory.xjph.net/).

Manages screenshots taken by the user, allowing them to be automatically renamed and organized based on screenshot metadata.

It can also apply some simple post-processing, including resizing, addition text captions, or applying a watermark.

Additionally Photographer can embed the Elite Dangerous metadata into the EXIF data of the screenshot, allowing for other tools to read and make use of it, or simply to retain the information for later reference by the user.

For full documentation and download links please refer to the [Observatory docs site](https://observatory.xjph.net/usage/plugins/photographer).
